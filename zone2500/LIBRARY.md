# Библиотека зоны 2500 (диск 2348) — ГОСТ-шифрование

Персональная библиотека (PERSO) Монитора-80 с **только** библиотекой
шифрования. Пересобрана 29.10.26 из прежней слитой библиотеки ( compiler +
обвязка + ГОСТ ) методом извлечения модуля через `*LIBLIST`.

## Состав

**Один модуль `GOSTLIB`** (5 зон тела, зоны 2502-2506₈) с дополнительными
точками входа (все адреса — смещения в словах от начала тела модуля):

| Имя каталога | Тип | Смещение |
|--------------|-----|----------|
| `GOSTLIB`    | главный модуль | 0 |
| `GOSTINIT`   | точка входа | 03117₈ (3279) |
| `TESTPWD`    | точка входа | 03066₈ (3190) |
| `TESTHASH`   | точка входа | 04471₈ (2361) |
| `TESTEQUA`   | точка входа | 02046₈ (1062) |
| `ROT11`      | точка входа | 0377₈ (255) |
| `ADD32`      | точка входа | 0167₈ (119) |

Плюс стандартная заглушка `PROGRAM` (служебное слово 0), которую монитор
добавляет в каждый каталог.

Библиотека занимает **7 зон**: 2500-2501₈ — каталог, 2502-2506₈ — тело.
Штамп каталога: `LIBRARY OT 29.10.26`.

## Происхождение

Исходники GOSTLIB/GOSTINIT/TESTPWD/TESTHASH/TESTEQUA утрачены; модуль
извлечён из слитой библиотеки 2500 образца 25.10.26 в байт-точном виде
средствами самого монитора:

```
*table:liblist(GOSTLIB)
*liblist:402500
*to perso:402500        (после загрузки во временный каталог)
```

`*LIBLIST` переносит модуль ВМЕСТЕ с дополнительными точками входа —
они хранятся в каталоге, а не в теле модуля.

## Важно

- Модуль хранится в библиотеке **привязанным к адресам**: при переносе в
  другую библиотеку монитор сам переразмещает тело и пересчитывает старшие
  24 бита служебного слова (младшие 24 бита — длина/смещения — неизменны).
- Не редактировать каталог вручную: формат служебных слов поддерживает
  только монитор (LIBDRUM).
- Файлы `zone2500/0000/*.pas` — исторические исходники примитивов
  (ADD32, ROT11 и т.д.); компилировались отдельно, к текущему модулю
  GOSTLIB отношения не имеют.

## Проверка

```
шифр 419999 зс5^
лен 40(2348)^
*perso:402500
*table:liblist(GOSTLIB)
*liblist:402500
```
Монитор печатает штамп `LIBRARY OT ...` и находит `GOSTLIB`
(см. `work/gost_check.log`).
