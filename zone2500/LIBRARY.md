# Библиотека GOSTLIB (диск 2348) — ГОСТ 28147-89

Модуль `GOSTLIB` — библиотека шифрования для внешних вызовов из
компилируемых Паскаль-программ. Пересобрана **30.10.26** из исходника
`zone2500/gostlib.pas` (тела процедур подняты из
`golden/gost_08.05.2025_new.pas`).

Старая копия (каталог 29.10.26, 7 зон, точки `TESTPWD/TESTHASH/TESTEQUA`)
оставлена в зоне **2500** как резерв. Рабочая новая — в зоне **2560**.

## Подключение к компилируемой программе

```
шифр 419999 зс5^
лен 40(2348)^
eeв1а3
*name
*call yesmemory
*perso:402030          ← Паскаль-система (компилятор + обвязка)
*perso:402560,cont     ← GOSTLIB, ДО компиляции
*stand
*call *pascal
...текст программы...
*execute
*end file
``````
ЕКОНЕЦ
```

- `,CONT` дозаписывает модуль в уже загруженный каталог; модуль встаёт
  **после** runtime по свободному адресу (в прогонах — 02143 или 03160,
  зависит от размера программы). Программа остаётся на 01000.
- База модуля не фиксирована — в декларациях не должно быть абсолютных
  адресов; монитор/транслятор разрешает внешние имена по каталогу.
- `*perso:402560` **после** `*call *pascal` (или после компиляции)
  вытесняет программу — так делать нельзя (проверено, прогон «молчит»).

## Декларации для вызывающей программы

```
type
  W8 = Array[1..8] of Integer;
  S16 = Array[1..16] of Integer;
  CtxT = record
    roundkey: Array[1..32] of Integer;
    sbox: Array[1..8] of Array[0..15] of Integer;
  end;
  Block2 = Array[1..2] of Integer;
  W7 = Array[1..7] of Integer;
  PtrW = @Integer;
  Ciphertext = File of Integer;
var
  key: W8;
  s8, s7, s6, s5, s4, s3, s2, s1: S16;
  ctx: CtxT;
  w: Block2;
procedure GOSTINIT(var c: CtxT; k: W8;
  a8: S16; a7: S16; a6: S16; a5: S16;
  a4: S16; a3: S16; a2: S16; a1: S16); external;
procedure ENCBLOCK(c: CtxT; var t: Block2); external;
procedure DECBLOCK(c: CtxT; var t: Block2); external;
procedure ENCCTR(c: CtxT; txt: PtrW; res: PtrW;
  len: Integer; iv: Integer); external;
procedure DECCTR(c: CtxT; ctxt: PtrW; res: PtrW;
  len: Integer); external;
procedure MSGENCIV(c: CtxT; iv: Integer;
  var f: Text; var ctxt: Ciphertext); external;
procedure MSGDECIV(c: CtxT; iv: Integer;
  var ctxt: Ciphertext; var fres: Text); external;
```

## Правила диалекта (Паскаль 15.1, 28.10.26)

- **Одна группа `var` на блок**: второй `var` даёт ошибку 84.
- Внешние объявления (`procedure ...; external;`) — **после** var-группы
  и до `begin`. После последнего `end.` компилятор ждёт продолжения.
- В параметрах внешних объявлений обязательны **именованные типы**
  (нельзя `Array[1..8] of Integer` прямо в списке).
- Адрес элемента массива берётся как `ref(t[1])`. Оператор `@` в
  выражениях не поддерживается (только в описании типа: `PtrW = @Integer`).
- `Ciphertext = File of Integer`; текст — `Text`.
- S-box'ы передаются в порядке **s8, s7, …, s1**; внутри
  `ctx.sbox[1] := s1 … ctx.sbox[8] := s8`, а при обходе полубайтов снизу
  вверх используется `sbox[9-i]` (младший полубайт — через s8). Поэтому
  порядок массивов в вызове `GOSTINIT` менять нельзя.
- S-box'ы заполняются присваиваниями (по 2 элемента на строку);
  `.data`-секция в этой системе не работает.

## Проверенные векторы (прогоны 30.10.26)

| Тест | Результат на машине |
|------|---------------------|
| `ADD32(2271560481, 4275878552)` | `2252471737` |
| `XOR32(123, 456)` | `435` |
| `ROT11(2882400001)` | `1870138718` |
| `GOSTINIT` + `ENCBLOCK` (GOST2015 s-box, ключ из golden `TestGost89`) | `1323893221` / `3268987453` |
| `DECBLOCK` после `ENCBLOCK` | `4275878552` / `1985229328` — исходный блок |
| `ENCCTR`/`DECCTR`, 7 слов, iv=123 | выход совпал с эталонной семантикой; roundtrip восстановил все 7 слов |
| `MSGENCIV`/`MSGDECIV`, текст `ABCDE` | roundtrip, 5 символов (нечётная длина) |

Важно: вектор `1323893221/3268987453` — для **GOST2015** s-box'ов
(golden строки 3535-3542). С GOST94-боксами (`sh1..sh8`, строки
3544-3551) тот же ключ даёт `3536161338/2600692413`; оба варианта
roundtrip-корректны.

## Исходник и воспроизведение

- `zone2500/gostlib.pas` — исходник библиотеки.
- `work/build_gostlib.b6` — дека сборки: `*perso:402030` → `*stand` →
  `*call *pascal` → исходник → `*to perso:402540`.
- `work/ext_gostlib.b6` — извлечение готового модуля из библиотеки 402540
  в новую библиотеку 402560 (`*table:liblist(GOSTLIB)` + `*liblist:402540`
  → `*to perso:402560`), результат — 3 зоны.
- Каталог: `tools/plcatalog.sh 2348 2560`.

## Тестовые деки

- `work/tgost1_enc.b6` — GOSTINIT/ENCBLOCK/DECBLOCK, векторный тест.
- `work/tgost1_ctr.b6` — ENCCTR/DECCTR по памяти (7 слов, нечётная длина).
- `work/tgost1_msg.b6` — MSGENCIV/MSGDECIV roundtrip текстового файла.

Логи прогонов — рядом (`.log`). Все три деки запускаются на диске 2348
без зоны 2148.
