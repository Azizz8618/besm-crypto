# Изменения в библиотеке ГОСТ для БЭСМ-6

## Версия 2026-10-24

### Исправления runtime Pascal

#### 1. Удалены external-функции

**Проблема:** Модуль `gostcore.pas` использовал внешние функции:
```pascal
function GSTADD(x, y: UInt32): UInt32; external;
function GSTXOR(x, y: UInt32): UInt32; external;
function GSTROT(x: UInt32): UInt32; external;
```

Runtime БЭСМ-6 не поддерживает внешние ссылки. Все функции должны быть inline.

**Решение:** Все функции реализованы внутри модуля:
- `GSTADD` - сложение по модулю 2^32
- `GSTXOR` - побитовое XOR
- `GSTROT` - циклический сдвиг на 11 бит

#### 2. Исправлена 32-битная арифметика

**Проблема:** Константа `gstMod32 := 4294967296` не могла быть глобальной переменной из-за ограничений инициализации.

**Решение:** Добавлены переменные в секцию var и инициализация в главном блоке:
```pascal
var
  gstMod32: Integer;  { 2^32 }
  gstMod31: Integer;  { 2^31 }

begin
  gstMod32 := 4294967296;
  gstMod31 := 2147483648;
  ...
end.
```

#### 3. Соответствие ограничениям диалекта

✅ Все строки ≤ 72 символов  
✅ Директива `(*=e+*)` присутствует  
✅ Имена различаются в первых 6 литерах  
✅ Нет внешних зависимостей
