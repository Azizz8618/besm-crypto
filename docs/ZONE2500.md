# Зона 2500 - Библиотека ГОСТ 28147-89

## Описание

Библиотека подпрограмм для диска 2348, зона 2500. Каждая подпрограмма может вызываться как external.

## Создано файлов

- **9 модулей Pascal** (500 строк кода)
- **Документация** (LIBRARY.md, MANIFEST.txt)
- **Тест** (testzone.pas)

## Модули

### Базовые операции

1. **add32.pas** - Add32(x, y): сложение по модулю 2^32
2. **xor32.pas** - Xor32(x, y): побитовое исключающее ИЛИ
3. **rot11.pas** - Rot11(x): циклический сдвиг влево на 11 бит

### Трансформации

4. **sbox8x4.pas** - Sbox8x4(box, x): применение 8 S-боксов
5. **feistel.pas** - FeistelRound(ctx, txt, r): раунд Фейстеля

### Шифрование

6. **encblk.pas** - EncryptBlock(ctx, txt): шифрование блока
7. **decblk.pas** - DecryptBlock(ctx, txt): расшифрование блока

### Инициализация

8. **initkey.pas** - InitGostCtx(ctx, key, sbox): инициализация

### Тестирование

9. **testzone.pas** - TestZone2500(): проверка всех модулей

## Использование

```pascal
program MyApp(output);
type
  UInt32 = Integer;
  W2 = Array[1..2] of UInt32;

Function Add32(x, y: UInt32): UInt32; external;
Function Xor32(x, y: UInt32): UInt32; external;
Function Rot11(x: UInt32): UInt32; external;

var
  a, b, c: UInt32;

begin
  a := 100;
  b := 200;
  c := Add32(a, b);  (* → 300 *)
  c := Xor32(5, 3);  (* → 6 *)
  c := Rot11(1);     (* → 2048 *)
end.
```
