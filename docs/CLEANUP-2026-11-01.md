Дата: 01.11.26. Выполнено по результатам сборки библиотеки ARFALIB
(см. `dispak/tests/arfalib` в проекте ДИСПАК) и проверки самодостаточной
библиотеки в зоне 02570.

Проверка после чистки: тест `testarfa` (зашифрованные отрывки через
внешние процедуры ARFALIB) и тест `pascal-arfa` (монитор областей)
проходят от одной строки загрузки `*perso:402570`; полный прогон
тестов ДИСПАК — 51/51. Компиляция golden-деки (3529 строк) —
побайтово та же структура (`3529 LINES STRUCTURE 1 476 0 0 12 5268
0 2589 258 19`), полный pty-диалог golden — открытый пункт: не
компонуется модуль P/LV штатного runtime (эталон `work/golden_pty.log`
от 31.10.26, получен на связке 02030+02000).

## Сопутствующие исправления (найдены при проверке библиотеки 02570)

1. **ARFALIB без глобальных переменных.** Глобали объектного модуля
   библиотеки компоновщик размещает поверх данных вызывающей
   программы: `isw` модуля ложится на смещение 42 кадра задачи
   (установлено тестами: `fragA[1] = isw[3] = (n3, sc)`,
   `fragA[2].l = kl.l = 'КЛЮЧАР'`). Всё состояние переведено в
   локальные переменные процедур; контекст ГОСТ передаётся `var`.
2. **Длина строк деки ≤ 72 символа.** Ввод обрезается по 72-й
   колонке: объявление `procedure ARFACRE(...); external;` длиной 74
   знака теряло хвост `l;`, компилятор выдавал каскад ложных ошибок
   84/12/52. Строки длиннее 120 знаков дают «ОШИБКИ ВВОДА».
