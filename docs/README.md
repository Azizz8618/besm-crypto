# Библиотека ГОСТ 28147-89 для БЭСМ-6

Реализация криптографического алгоритма ГОСТ 28147-89 на диалекте Паскаля для ЭВМ БЭСМ-6.

## Статус проекта

✅ **Ядро алгоритма реализовано и исправлено**
- Устранены проблемы с external-функциями
- Все функции теперь inline (как требует runtime БЭСМ-6)
- Исправлена работа с 32-битной арифметикой
- Добавлены необходимые модули утилит

## Структура проекта

### Исходный код (`src/`)

- `gostcore.pas` - Ядро ГОСТ 28147-89:
  - Блочное шифрование ECB
  - 32-раундовая сеть Фейстеля
  - Управление контекстом
  - Функции: GOSTINI, GOSTENC, GOSTDEC, GOSTSET

- `gostmode.pas` - Режимы шифрования:
  - CTR (счетчиковый режим)
  - Хеш-функция ГОСТ Р 34.11
  - Функции: ENCCTR, DECCTR, HSHSTP

- `gostbox.pas` - S-боксы:
  - ГОСТ 28147-89 (идентификатор C)
  - ГОСТ Р 34.12-2015 (Кузнечик)
  - ГОСТ 28147-89 (тестовые для хеша)

- `gstutil.pas` - Утилиты:
  - GSTRVS - обращение 32 бит
  - GSTSWP - обмен слов
  - GSTA256 - сложение mod 2^256

- `testgost.pas` - Базовый тест шифрования
- `testall.pas` - Комплексный тест всех функций

## Ключевые исправления

### 1. Устранены external-функции

**Проблема**: gostcore.pas использовал external-функции GSTADD, GSTXOR, GSTROT, которые не работают на runtime БЭСМ-6.

**Решение**: Все функции реализованы inline внутри модулей:
- GSTADD - сложение по модулю 2^32
- GSTXOR - побитовое исключающее ИЛИ  
- GSTROT - циклический сдвиг на 11 бит

### 2. Исправлена 32-битная арифметика

**Проблема**: gstMod32 не мог хранить значение 4294967296 из-за ограничений типа.

**Решение**: Добавлены переменные gstMod32 и gstMod31 в main block:
```pascal
begin
  gstMod32 := 4294967296;
  gstMod31 := 2147483648;
  ...
end.
```

### 3. Соответствие ограничениям БЭСМ-6

- Все строки короче 72 символов ✅
- Директива `(*=e+*)` для расширенного синтаксиса ✅
- Имена функций различаются в первых 6 литерах ✅
- Нет внешних ссылок, все inline ✅

## Точки входа

### gostcore.pas (основной модуль)

```pascal
GOSTINI(var c: Ctx; k: W8; b: SB)  - Инициализация контекста
GOSTSET(var c: Ctx; k: W8)         - Установка ключа  
GOSTENC(var c: Ctx; var t: W2)     - Шифрование 64-битного блока
GOSTDEC(var c: Ctx; var t: W2)     - Расшифрование блока
```

### gostmode.pas (режимы работы)

```pascal
ENCCTR(c: Ctx; var txt: W2; cnt: W2; num: Integer)
DECCTR(c: Ctx; var txt: W2; cnt: W2; num: Integer)
HSHSTP(var hs: W8; ms: W8; c: Ctx)
```

## Сборка и тестирование

### Компиляция отдельных модулей

```bash
pascal src/gostcore.pas
pascal src/gostmode.pas
pascal src/gostbox.pas
pascal src/gstutil.pas
```

### Запуск тестов

```bash
pascal src/testgost.pas
run testgost

pascal src/testall.pas  
run testall
```
