# Сборка библиотеки ГОСТ для БЭСМ-6

## Требования

- Симулятор БЭСМ-6 или реальная ЭВМ БЭСМ-6
- Компилятор Паскаля для БЭСМ-6

## Структура библиотеки

### Основные модули

- `src/gostcore.pas` - Ядро ГОСТ 28147-89
  - Блочное шифрование в режиме ECB
  - Управление контекстом
  - 32-раундовая сеть Фейстеля

- `src/gostmode.pas` - Режимы шифрования
  - CTR (счетчиковый режим)
  - Хеш-функция ГОСТ Р 34.11
  - Дополнительные режимы

- `src/gostbox.pas` - S-боксы
  - ГОСТ 28147-89 (идентификатор C)
  - ГОСТ Р 34.12-2015 (Кузнечик)
  - ГОСТ 28147-89 (тестовые для хеша)

- `src/gstutil.pas` - Утилиты
  - Арифметика по модулю 2^32
  - 256-битное сложение
  - Обращение бит

### Тестовые программы

- `src/testgost.pas` - Базовый тест шифрования
- `src/testall.pas` - Комплексный тест всех функций

## Компиляция

### Отдельные модули

```bash
pascal src/gostcore.pas      # Компиляция ядра
pascal src/gostmode.pas      # Компиляция режимов
pascal src/gostbox.pas       # Компиляция S-боксов
pascal src/gstutil.pas       # Компиляция утилит
```

### Тесты

```bash
pascal src/testgost.pas      # Компиляция базового теста
run testgost                 # Запуск теста

pascal src/testall.pas       # Компиляция комплексного теста
run testall                  # Запуск теста
```

## Создание библиотеки (LIBRA)

Для объединения модулей в библиотеку на БЭСМ-6:

```
*pascal
*libra: 13
program gostlib;
%include src/gostcore.pas
%include src/gostmode.pas  
%include src/gostbox.pas
%include src/gstutil.pas
begin
end.
```

## Особенности БЭСМ-6

1. **Ограничения строк**: максимум 72 символа в строке
2. **Директивы**: `(*=e+*)` для расширенного синтаксиса
3. **Имена**: различаются в первых 6 значащих литерах
4. **Типы**: Integer используется для UInt32 (0..4294967295)
5. **Внешние функции**: не поддерживаются, все функции inline

## API

### gostcore.pas

```
GOSTINI(var c: Ctx; k: W8; b: SB)  - Инициализация контекста
GOSTSET(var c: Ctx; k: W8)         - Установка ключа
GOSTENC(var c: Ctx; var t: W2)     - Шифрование блока
GOSTDEC(var c: Ctx; var t: W2)     - Расшифрование блока
```

### gostmode.pas

```
ENCCTR(c: Ctx; var txt: W2; cnt: W2; num: Integer) - CTR шифрование
DECCTR(c: Ctx; var txt: W2; cnt: W2; num: Integer) - CTR расшифрование
HSHSTP(var hs: W8; ms: W8; c: Ctx)                 - Шаг хеша
```

### gstutil.pas

```
GSTRVS(x: UInt32): UInt32                  - Обращение бит
GSTSWP(var a, b: UInt32)                   - Обмен значений
GSTA256(var ss: W8; xs: W8)                - Сложение mod 2^256
```
